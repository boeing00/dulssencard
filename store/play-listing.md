덜쎈카드

### 짧은 설명 (80자)

```
카드 결제 알림을 읽어 카드별 실적을 자동으로 셉니다. 인터넷 권한 없음 — 기록은 폰 밖으로 나가지 않습니다.
```

### 전체 설명 (4000자)

```
카드 실적, 매번 앱 열어서 확인하시나요?

덜쎈카드는 결제 알림이 올 때마다 금액을 읽어 카드별 이번 달 사용액을 대신 세어 줍니다.
목표까지 얼마 남았는지 홈 화면에서 한눈에 보입니다.

■ 인터넷에 접속하지 않습니다

이 앱에는 인터넷 권한이 아예 없습니다. 약속이 아니라 구조입니다.
권한이 없으니 결제 기록을 어디로도 보낼 수 없습니다. 서버도, 계정도, 로그인도 없습니다.
Play 스토어 앱 정보에서 권한 목록을 직접 확인해 보세요.

■ 알림 접근 하나로 끝

문자 읽기 권한을 요구하지 않습니다. 결제 알림을 읽는 권한 하나만 씁니다.
그마저도 사용자가 고른 앱(카드사·은행·문자 앱)의 알림만 봅니다.
목록에 없는 앱의 알림은 읽지 않고, 결제가 아닌 알림은 버립니다.

■ 기록은 암호화해서 폰 안에만

- 데이터베이스는 SQLCipher 로 암호화합니다. 파일을 꺼내도 열리지 않습니다.
- 그 암호는 Android 키 저장소가 봉인합니다. 이 폰 밖에서는 풀리지 않습니다.
- 알림 본문, 발신 번호, 카드번호는 저장하지 않습니다. 금액·시각·가맹점만 남깁니다.

■ 이렇게 씁니다

1. 알림 접근을 켜고, 결제 알림이 오는 앱을 고릅니다.
2. 카드를 등록하고 이번 달 목표 금액을 적습니다.
3. 이미 쓴 금액이 있으면 '초기 사용액'으로 한 번만 입력합니다. 그 다음부터는 알림으로 쌓입니다.
4. 결제할 때마다 홈의 숫자가 올라갑니다.

■ 틀리면 바로 고칩니다

- 실적에 넣지 않을 결제는 '제외'하고, 필요 없으면 영구 삭제합니다.
- 금액을 잘못 읽었으면 직접 고칩니다.
- 알림이 안 온 결제는 직접 추가합니다.
- 취소 결제는 원래 결제에 이어 붙여 합계에서 뺍니다.
- 무엇을 하든 4.2초 안에 되돌릴 수 있습니다.

■ 백업

비밀번호를 정해 암호화 파일로 내보내고, 다른 기기에서 그 비밀번호로 가져옵니다.
비밀번호는 앱에 저장하지 않습니다 — 잃어버리면 열 수 없습니다.
복구하기 전에 지금 데이터를 자동으로 한 번 백업해 둡니다.

■ 무료 범위

카드 2장까지 무료입니다. 더 쓰시려면 한 번만 결제하면 됩니다. 구독이 아닙니다.

■ 이런 분께

- 카드마다 실적 조건이 달라 매달 헷갈리는 분
- 가계부 앱에 계좌를 연결하기 싫은 분
- 결제 내역이 서버로 올라가는 게 불편한 분
```

심사자가 알림 접근을 켜야 수집이 보이므로, 아래 '심사자 안내'를 함께 적는다.

### 콘텐츠 등급

설문에서 모두 "아니요" (폭력·성적 내용·욕설·약물·도박·사용자 간 소통·위치 공유 없음).
분류: 유틸리티 / 금융.

### 타겟층

만 18세 이상. 아동 대상 아님.

### 데이터 안전성 (Data safety)

Play 의 '수집'은 **기기 밖으로 전송하는 것**을 뜻한다. 이 앱은 인터넷 권한이 없어
어떤 데이터도 전송하지 않는다.

| 질문 | 답 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **아니요** | `INTERNET` 권한 미선언 — 전송 경로 자체가 없다 |
| 데이터가 전송 중 암호화됩니까? | 해당 없음 (전송 없음) | |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 해당 없음 (개발자가 보유하지 않음) | 설정 → 전체 삭제로 기기에서 지운다 |

> 주의: ML Kit·Play 결제 라이브러리가 `transport-backend-cct` 를 끌고 오지만,
> 인터넷 권한이 없어 실제 전송은 일어나지 않는다. 데이터 안전성 답을 바꾸지 말 것.
> Google Play 결제로 처리되는 구매 정보는 Google 이 수집하는 것이라 앱이 신고하지 않는다.

### 보안 관행

- 저장 데이터 암호화: 예 (SQLCipher + Android Keystore AES-256-GCM)
- 전송 중 암호화: 해당 없음 (전송 없음)

## 3. 알림 접근 권한 심사 자료

`BIND_NOTIFICATION_LISTENER_SERVICE` 는 민감 권한으로 분류돼 권한 선언 양식을 요구받을 수
있다. 아래를 그대로 쓴다.

### 핵심 기능성 (왜 필요한가)

```
덜쎈카드의 유일한 기능은 카드 결제 알림에서 결제 금액을 읽어 카드별 월 사용액을 집계하는
것입니다. 알림 접근이 없으면 앱은 아무 데이터도 얻을 수 없어 기능이 전혀 동작하지 않습니다.
알림 접근은 부가 기능이 아니라 앱의 유일한 데이터 수집 경로입니다.
```

### 다른 방법이 없는 이유

```
대안은 SMS 읽기 권한(READ_SMS)이지만, 이는 더 민감한 권한이며 문자로 오지 않는
카드사 앱 푸시·알림톡 결제 통지를 받을 수 없습니다. 계좌·카드 연동 API 는 별도 인증과
서버 통신을 요구하므로, 데이터를 기기 밖으로 내보내지 않는다는 이 앱의 설계와 맞지 않습니다.
저희는 더 좁은 권한 하나만 쓰는 쪽을 택했습니다.
```

### 데이터 취급

```
- 사용자가 설정에서 직접 고른 앱(카드사·은행·문자 앱)의 알림만 읽습니다. 허용 목록 방식입니다.
- 읽은 알림 중 결제로 판정된 것만 처리하고 나머지는 즉시 버립니다.
- 알림 본문 원문과 발신 번호는 저장하지 않습니다. 금액·시각·가맹점·카드사 라벨만 저장합니다.
- 중복 판정에는 되돌릴 수 없는 해시(지문)를 씁니다.
- 저장은 SQLCipher 로 암호화하고, 그 암호는 Android Keystore 가 봉인합니다.
- 앱은 INTERNET 권한을 선언하지 않습니다. 읽은 알림 데이터는 기기를 떠날 수 없습니다.
```

### 심사자 안내 (테스트 방법)

```
1. 앱을 실행하면 온보딩이 알림 접근 설정 화면으로 안내합니다.
   설정 > 알림 > 기기 및 앱 알림 에서 '덜쎈카드'를 허용해 주세요.
2. 온보딩 2단계에서 결제 알림이 오는 앱(문자 앱 등)을 선택합니다.
3. 온보딩 3단계에서 카드를 등록합니다. 카드 매칭 키워드에 '1234' 를 넣어 주세요.
4. 아래 문구로 본인에게 문자를 보내면 결제로 인식되어 홈 화면 합계에 반영됩니다.

   [Web발신] 신한카드(1234)승인 홍*동 12,500원 일시불 09/08 10:05 스타벅스 서초

5. 알림 접근을 끄면 수집이 즉시 멈춥니다.

이 앱은 로그인이 없으며 모든 기능을 제한 없이 사용할 수 있습니다.
```
